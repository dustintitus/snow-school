Google availability connection

The school's Google script reads instructor-reviewed availability once an hour. It updates App Availability and the weekday summaries in the master schedule.

Only the Google account and client ID below can read this feed. The feed includes instructor names, emails, dates and availability; it excludes participant records and private profile details.

Run appAvailabilityConnectionInfo in the Google script and copy its client ID. This is a public identifier, not a password or token.
